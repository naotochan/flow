# Feedback sounds

Place short UI feedback clips here (then rebuild), or drop the same filenames into:

`~/Library/Application Support/com.flow.app/sounds/`

(no rebuild — overrides the bundled files)

| File stem | When |
|-----------|------|
| `start` | Recording starts |
| `done` | Transcription pasted / finished successfully |
| `error` | Recording or pipeline failure |

Supported extensions: `.wav` `.aiff` `.aif` `.caf` `.mp3`

Keep clips short (≈0.1–0.4s) and not too loud. Missing files are silent.
